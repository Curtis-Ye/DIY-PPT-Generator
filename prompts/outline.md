# PPT Outline Generator

## 任务

根据文档的章节结构，生成 PPT 大纲。你需要理解文档的核心叙事逻辑，将其转化为适合演示的线性结构。

## 大纲设计原则

1. **金字塔结构**: 先总后分、先结论后展开
2. **故事线**: 为什么做 → 怎么做的 → 结果如何 → 未来怎样
3. **节奏控制**: 重要内容独占一页，次要内容合并

## 页数分配建议

用户会指定目标总页数 N（默认为 15）。按以下比例分配：

| 部分 | 占比 | 说明 |
|------|------|------|
| 封面 | 1 页 | 标题、作者、日期 |
| 目录 | 1 页 | 章节导航 |
| 背景/动机 | ~15% | 为什么做这个工作 |
| 方案/方法 | ~35% | 核心内容，适当展开 |
| 实验/验证 | ~25% | 数据、图表、分析 |
| 总结/展望 | ~15% | 结论、未来工作 |
| 致谢 | 1 页 | 结束页 |

例如用户指定 15 页：封面1 + 目录1 + 背景2 + 方案5 + 实验4 + 总结2 + 致谢1 = 16，可在各部分间微调以精确匹配目标页数。

## 输出格式

```json
[
  { "page": 1, "title": "封面", "source_sections": ["文档标题"] },
  { "page": 2, "title": "目录", "source_sections": [] },
  { "page": 3, "title": "研究背景与意义", "source_sections": ["第1章"] },
  { "page": 4, "title": "国内外研究现状", "source_sections": ["第2章"] }
]
```

- `source_sections`: 该页内容对应文档中的哪些章节，用于后续内容提取
