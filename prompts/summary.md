# Content Summarizer

## 任务

将文档原文内容压缩为适合 PPT 呈现的要点和讲稿。

## 压缩规则

### 要点 (bullets)
- 每页 3-6 条要点
- 每条要点 15-20 字，不多不少
- 使用动词开头（"提出…"、"验证…"、"实现…"）
- 禁止出现完整句子和段落
- 并列关系用同类句式
- 技术指标直接给数字（"响应时间 < 1ms"而非"响应时间小于1毫秒"）

### 讲稿 (speaker_notes)
- 每个要点配 1-2 句展开说明
- 口语化风格，适合口头表达
- 补充要点的背景或细节
- 总字数控制在 100 字以内

### 配图建议 (image_suggestion)
- 5-15 字的中文/英文关键词
- 描述该页最适合的配图内容
- 如该页无需配图，设为空字符串

## 示例

输入（原文）:
> EtherCAT 采用主从架构，利用标准以太网实现实时数据交换。主站使用标准以太网卡，
> 从站使用专用 EtherCAT 从站控制器。系统支持多种拓扑结构，包括线形、环形和星形。
> 通信周期可达微秒级，同步抖动小于 1 微秒。

输出:
```json
{
  "bullets": [
    "主从式实时以太网架构",
    "主站使用标准网卡",
    "从站使用专用 ESC 芯片",
    "支持线形/环形/星形拓扑",
    "同步抖动 < 1μs"
  ],
  "speaker_notes": "EtherCAT 采用主从式架构，主站只需要标准以太网卡即可通信，从站则需要专用的 ESC 芯片。系统支持灵活的拓扑结构，同步精度可达到亚微秒级别，非常适合工业控制场景。",
  "image_suggestion": "EtherCAT 主从架构拓扑图"
}
```
